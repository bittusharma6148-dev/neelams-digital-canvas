# Neelam's Digital Canvas 🎨

Official Creative Portfolio, Brand Identity Architecture & Live Interactive Studio for **Neelam**.

---

## 🚀 Live Localhost Server

To run the application locally on your machine:
1. Double-click `start-server.bat` **OR**
2. In PowerShell, run:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\server.ps1
   ```
3. Open your browser and navigate to:
   👉 **http://localhost:3000**

---

## 📦 Features Included

- **Interactive Live Drawing Canvas**: Real-time sketchpad with multi-color brush options, eraser, brush-size adjustment, and 1-click PNG artwork export.
- **Filterable Portfolio Showcase**:
  - Real Estate Branding & Marketing Collaterals (SkyArc Estate, DV Dream City 2, etc.)
  - High-Converting Meta Ads (Facebook & Instagram campaigns)
  - Corporate Identity Suites & Letterheads (Satya Homes)
  - UI/UX Digital Systems
  - Affordable Housing Campaign Design
- **Responsive & Modern Design**:
  - Built with Tailwind CSS, Google Fonts ('Outfit', 'Plus Jakarta Sans'), and Lucide Icons.
  - Glowing ambient neon gradients and dark-mode aesthetic.
  - Interactive project detail modal previews.
- **Direct Contact Channel**:
  - Interactive contact form with local confirmation.
  - Direct WhatsApp click-to-chat integration.
  - Response time and email channels.
- **One-Click Local Web Server**:
  - Native Windows PowerShell HTTP server with MIME type recognition and fast loading.
